# Report Executive Summary Skill

Use this auxiliary skill for the Executive Summary section of a report.

Write the section with this shape:

1. One answer-first lead sentence.
2. Two to four high-signal bullets or short paragraphs.
3. One sentence on what the reader should do or watch next.

Avoid background detail unless it changes the conclusion.
