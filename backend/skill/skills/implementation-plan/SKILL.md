# Implementation Plan Skill

Use this as the primary skill when a task asks for a code change or feature.

Follow this process:

1. Identify the smallest useful change.
2. Keep edits scoped to the requested behavior.
3. Run a focused verification command.
4. Report changed files and verification results.
