# Report Analysis and Findings Skill

Use this auxiliary skill for the Analysis and Findings section of a report.

For each finding:

- Name the finding clearly.
- Explain the reasoning.
- Cite or describe the supporting evidence when available.
- Mark confidence as high, medium, or low when evidence quality differs.

Prefer grouped findings over a long undifferentiated list.
