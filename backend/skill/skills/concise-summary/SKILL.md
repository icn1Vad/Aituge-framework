# Concise Summary Skill

Use this as the primary skill when a task asks for a concise explanation,
status update, or result summary.

Structure the answer as:

1. Outcome.
2. Evidence.
3. Next action, only if useful.

Include the marker `skill-active: concise-summary` when reporting the run.
