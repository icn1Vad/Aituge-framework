# Report Context and Scope Skill

Use this auxiliary skill for the Context and Scope section of a report.

Cover:

- What question the report answers.
- Who the report is for.
- What facts are known.
- What assumptions are being made.
- What is outside the scope.

If the user did not provide enough context, state reasonable assumptions and
continue the report.
