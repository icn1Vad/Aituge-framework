## 12. 必须执行的测试

- [ ] 单元测试：事件触发、错误码、脱敏、重试不覆盖。
- [ ] 数据库迁移与回滚测试。
- [ ] 租户管理员只能看到本租户。
- [ ] 超级管理员跨租户查询被安全审计。
- [ ] 无权限、伪造租户、伪造角色、内部 Token 失效测试。
- [ ] 日志扫描不含 Secret、认证头、正文、完整 Prompt/Response。
- [ ] requestId/traceId/taskId/runId 能贯穿流程。
- [ ] 异步 Worker/回调使用新 Trace + Span Link，主时间线按 taskId/runId 拼接。
- [ ] 业务状态、事件和 Outbox 原子提交；命令和回调重复投递不产生重复终态/扣费/结果。
- [ ] 模型 logical_call、invocation、生命周期事件及两种成功率统计口径测试。
- [ ] 模型 RUNNING 与 UNKNOWN 终态严格区分；RUNNING 的 outcome 为空且不进入终态成功率分母。
- [ ] 未知终态事件为 `MODEL_INVOCATION_OUTCOME_UNKNOWN`，投影 outcome 为 `UNKNOWN`；Java、Python 与数据库枚举映射一致。
- [ ] 输入 Guardrail、凭据和路由前置失败不创建 invocation；三种 dispatchStatus、输出 Guardrail 和实际请求统计口径通过测试。
- [ ] 摄取高水位/PIT 能排除快照后的晚到事件。
- [ ] Task/invocation 可变投影按物化结果清单翻页；状态变化不造成跨页重漏，投影版本可复核。
- [ ] Alert 与包含运行中 Trace 的列表同样使用物化结果清单；其他会 UPDATE 且参与分页/状态筛选的资源已登记。
- [ ] Task、Invocation、Security、Runtime、Trace、Alert 使用基线固定排序，并以唯一 ID/tie-breaker 消除同一时间戳歧义。
- [ ] Task/Run/跨来源三个分页时间线按登记的升序固定排序翻页，同 sequence/时间戳下以 eventId 消除重复和遗漏。
- [ ] 任一来源超时时 `nextCursor=null`、`hasMore=null`，只能把 retryToken 作为同名输入重试当前页；cursor/retryToken 同传返回 400。
- [ ] 统一事件不能查询 SECURITY_EVENT；导出不会绕过 security/runtime/operations/cross-tenant 权限。
- [ ] `UnifiedEvent.source` 枚举不含 Security/Runtime，DTO 不含 `runtimeMessage`；专用接口之外无法生成这两类返回。
- [ ] 跨租户详情无 Access Context、Token 过期、范围/原因不匹配，或目标资源租户不属于原查询范围时均被拒绝。
- [ ] 新建跨租户 Session 从 `X-Observability-Access-Reason` 生成统一上下文；自动刷新只复用有效 Access Session，运行日志和导出 Body 不接受原因字段。
- [ ] 跨租户自动刷新复用 Access Session；Java/Python 子事件沿用同一 auditActionId，行为统计不会随轮询或下游调用数放大。
- [ ] 模型列表一行一个 invocation，详情显示生命周期；摘要由投影侧聚合。
- [ ] 原生 EventSource 不作为实现；fetch 流携带 Bearer，sequence 断线恢复和去重通过。
- [ ] SSE `id` 与 `Last-Event-ID` 都是 eventId；data 使用 `sequence`，不存在 `seq` 或把 sequence 当 Last-Event-ID 的实现。
- [ ] Service JWT 可短期复用；每个下游调用 Scope Token 独立绑定 method/path/queryHash/requestId。
- [ ] mTLS 在实际网关/Service Mesh/TLS 配置中验收，不能只检查 OpenAPI 扩展。
- [ ] 安全审计应用账号无 UPDATE/DELETE，查询和 retention 账号隔离，清理/修复可审计。
- [ ] 未解析租户、匿名主体和服务认证失败可写为 SYSTEM 安全事件；缺失上下文有原因且无空对象占位。
- [ ] Loki/Tempo/Prometheus/采集器不可用时业务仍成功。
- [ ] 10 天测试留存边界和批量清理测试。
- [ ] 管理员接口游标、时间线分页、最大时间窗、最大页大小、速率限制。
- [ ] Task/Model 跨租户列表的 `tenantId` 必填；缺失时契约测试失败且不得猜测租户。
- [ ] Export discriminator 的七个 filterType 均有明确 Schema mapping，并完成 Java/TypeScript/Python 反序列化烟测。
- [ ] 每用户活跃快照上限、30 秒复用、旧快照回收、过期清理、存储容量指标和 `OBSERVABILITY_SNAPSHOT_CAPACITY_EXCEEDED` 压力测试。
- [ ] 冻结列表与实时详情分别返回 `projectionVersion/dataAsOf`；版本变化能提示“状态已更新”，接口不声称支持历史 as-of 详情。
- [ ] Java—Python highWatermark 只接受符合长度与格式限制的 `hwm_...` 短句柄；原生 PIT、长 JWT、租户和筛选明文均被拒绝且不进入访问日志。
- [ ] cursor、retryToken、locator、Access Context/Session 和 highWatermark 在应用、网关、APM 与 Loki 中全部脱敏，管理员响应禁止缓存。
- [ ] 异步导出在创建时冻结快照；Worker 不越过快照边界；状态与下载重新校验原资源权限、租户范围、下载者和有效期。
- [ ] 真实测试与 Mock 证据分开标注。
