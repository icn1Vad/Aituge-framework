# 批次失败隔离与当前财务／证据流程

## 本轮修改

- 删除生产 Direct 链路的 `_require_complete_review_phase`，基础域、横向域出现部分失败后仍继续执行、合并并返回已验证的 Finding。
- 不删除批次校验、不填造证据，不将 FAILED／INSUFFICIENT_EVIDENCE 改成 NO_RISK。原始诊断和逐检查记录保留。
- 新增 `review_completion`，从实际检查记录计算未完成范围，写入 Framework 阶段 metadata。未完成范围也进入正式结果 `summary.overview`，因此沿现有 Python → Java → 前端／报告上下文传递，无新增数据库字段。
- “待复核”包括执行失败、证据不足、范围不足或未形成确定结论，不能把待复核项数量当作程序 Bug 数量。规则 `COMPLETED` 也可能仍包含 `INSUFFICIENT_EVIDENCE` 判断，摘要单独披露这些记录。
- 在原风险列表中显示现有摘要。没有 Finding 时使用“本次未返回风险项”，不再单凭空数组宣称审查全部完成、合同无风险。
- 在规则风险合并／去重以后重新计算摘要数量，同时披露规则库未完成或证据不足的记录；仅重建展示摘要，不修改判断、证据或历史结果。
- 部分结果仍可完成正常结果落库与回调，任务进入待人工复核。局部失败状态保留；不启动自动整单重试，也不覆盖历史任务。
- 所有基础批次都失败、用户取消、合同身份／版本不一致、最终证据无法验证或落库失败，仍不是可伪装的有效结果。这次改变的是单个／部分批次失败向整单升级的行为。

## 当前财务审查如何工作

1. **程序准备输入。** 按冻结的合同事实、原文位置和检查计划组成财务批次；带我方立场、双方名称、本批实际分配的问题、判定政策和范围记录。适用且已分配的法律正文作为另一个目录发送。不是每次默认回答全部八项，也不是每次都发整份合同。
2. **程序先提取付款观察。** `payment_facts.py` 的正则、词组和规则识别谁付款、履约前后、比例和保障机制，生成 CF-005 待核实材料。例如付款比例大不直接代表预付款。无法识别的情况保留 UNKNOWN。
3. **财务 AI 作判断。** 返回每项状态、判断理由、风险描述、建议，以及它选择的证据编号。有风险填写 Finding 的主要证据；无风险／不适用且有候选原文时，填写检查级判断证据；全文缺失另走有范围记录的缺失判断。CF-005 另有付款风险触发与保障判断字段。
4. **程序绑定并校验。** 共享证据层先将一个 Source ID 解回事实、原文和位置，检查编号、类型、字段形状；财务层再检查付款主体、时序、保障和范围等业务条件。第二层不是另一个 AI，而是确定性代码，所以可能与 AI 的语义判断冲突。
5. **最多一次现有局部修复。** 发送出错检查、错误字段、原始合同及法律目录；只替换目标项，未涉及项保持原样。目标项可以纠正标题、理由、结论和证据，不再冻结错误判断。整段 JSON 坏到无法定位检查项时，只重做这个财务批次，不重跑整份合同。
6. **交给汇总。** 可验证的批次产出 Finding，进入原七域风险卡片；修复仍失败的财务批次记为失败。本轮改动使后者不再阻止其他批次结果返回。财务同一批次内部仍不是完整逐项容错；本轮没有把整批输出解析重写为逐行提交。

## 共享证据层如何工作

- 原文示例：“甲方在设备验收合格后支付全部价款”。程序将这段原文、对应事实和位置绑定成一个 Source ID。
- 模型只选 Source ID，不自己填证据类型、不配对两个编号、不计算字符位置。程序负责还原不可变的原文绑定。
- 同一批、同一份冻结合同的原文可以跨检查引用；检索归类不再是引用权限。专用于某个范围的“缺失证明”不能任意跨检查复用。
- 单条 Finding 可继承模型明确放在所属检查项里的证据选择；多条 Finding 不由程序猜分配。两处都没选证据时也不凭检索候选自动补齐。
- 法条目录与合同原文目录分开，法条不能作为合同原文编号；当前法条采用仍依赖模型在说明中使用目录中的法条引用名称。
- “共享”指统一的证据协议与当前批次原文可复用，不代表独立模型调用天然共享记忆。超长分片仍必须记录范围限制。

## 需要讨论的设计点（本轮未擅自修改）

- Source ID 是否真实存在、是否属于当前合同、位置是否对应原文，是可确定验证的数据完整性，不等于 AI 理解法律。
- CF-005 等业务条件以词组／正则观察作为硬门槛，会有语义覆盖不足风险。某种表达未被程序识别，不自动证明 AI 判断错误；需要原文回放区分正确拦截和误伤。
- 无风险／不适用也要求证据能避免无依据放行，但应区分“有条款支持”“范围内未找到”“材料不足”，不应要求所有不同性质结论走相同的举证方式。
- 本轮只做批次失败隔离及其结果披露，未修改上述财务判断门槛、法条路由或身份匹配。
