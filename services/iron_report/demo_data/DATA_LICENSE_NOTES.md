# 数据与开源许可证说明

## 本数据集

- 新浪期货连续合约：当前未确认商业再分发条款，只作为内部 Demo 和测试快照；正式对外产品需确认数据授权或替换成获授权行情源。
- IMF/FRED：页面明确提示 IMF 版权并提供建议引用；使用时保留来源和引用，正式再分发前复核条款。
- World Bank Pink Sheet：保留世界银行来源和下载文件；正式再分发前复核 World Bank Terms of Use。
- 矿商和交易所新闻：只保存链接和自行概括的事实，不复制全文。

## BabelDOC（AGPL-3.0）

BabelDOC 是第三方开源项目，不是必须付费的商业 SaaS。开源并不等于可以无条件并入闭源产品：AGPL-3.0 通常要求向通过网络使用修改版或组合程序的用户提供对应源代码。项目作者也可能另行提供商业许可证，但是否收费、价格多少由作者决定。

在许可证没有确认前，我们可以：

- 阅读和独立验证；
- 参考它解决 PDF 排版问题的思路；
- 在隔离环境做内部技术试验。

不要直接把其代码或库链接进准备闭源交付的正式服务。

## FinSight（GPL-3.0）

FinSight 是第三方研究型开源项目。GPL-3.0 不代表必须向作者付费；它允许使用、研究和修改，但分发包含或链接其 GPL 代码的衍生程序时，通常需要按 GPL 提供对应源代码和同等自由。

因此当前采用以下边界：

- 可以学习“数据采集 → 搜索 → 代码分析/图表 → 报告导出”的架构；
- 可以让我们自己的 Framework 调用我们自己的模型 API、搜索和代码工具；
- 不复制、链接或打包 FinSight 源码；
- 如果只是调用对方独立部署且协议清晰的外部 HTTP API，需要另外审查其服务条款和部署关系，不能仅凭“隔了一个 API”就认定规避 GPL。

这不是正式法律意见；在对外销售或分发前应由法务确认具体集成方式。
